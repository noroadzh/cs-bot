# 企业微信申请资料说明

| 项 | 内容 |
|---|---|
| 文档名称 | 企业微信申请资料说明 |
| 版本 | V1.0 |
| 日期 | 2026-11-01 |
| 适用读者 | 客户行政、企微超级管理员、交付实施 |
| 适用系统 | 微信群智能客服机器人（私有化 / SaaS） |
| 关联文档 | 《部署手册》第 5、6 节、《用户使用手册》 |

本文说明两件事：注册并完成企业微信主体认证要备哪些材料；认证通过后，要把哪些后台参数交给实施，机器人才能进客户群收发消息。

审核材料、可选核验方式和认证费用以 [企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame) 当时页面为准。页面要求与本文不一致时，以页面为准。

## 1. 做到哪一步算申请完成

| 步骤 | 完成标志 | 责任 |
|---|---|---|
| 注册企业微信 | 能用管理员手机号登录管理后台，企业 ID 以 `ww` 开头 | 客户 |
| 主体认证通过 | 企业信息页显示已认证 / 已验证 | 客户（材料）+ 腾讯审核 |
| 创建自建应用 | 拿到企业 ID、AgentId、Secret | 客户管理员 |
| 配好接收消息 | Token、EncodingAESKey 已生成；部署完成后回调保存成功 | 客户 + 交付方联调 |
| 应用进入目标客户群 | 群内可以 @ 该应用 | 客户群主 |

实时问答不依赖会话内容存档。存档只在需要把历史聊天导入知识库时另开，见第 6 节。

## 2. 注册时当场要填的信息

入口：企业微信 App，或 [work.weixin.qq.com](https://work.weixin.qq.com/)。

| 信息 | 要求 |
|---|---|
| 企业或组织名称 | 与证照上的名称一致，后面认证时不能随意改成另一个主体 |
| 行业、人员规模 | 按实选 |
| 管理员姓名 | 真实姓名，建议就是能跟进认证补件的人 |
| 管理员手机号 | 本人实名手机号，用于验证码和管理后台登录 |

注册本身不上传营业执照。未认证时，成员规模、客户联系和服务器接口调用都会受限。本机器人要求先完成主体认证，再创建自建应用。

## 3. 主体认证要准备的材料

在管理后台进入「我的企业 → 企业信息」，按页面发起认证或主体验证。认证联系人要能接听手机、收取邮件，审核一般几个工作日；名称、公章或证照不一致会被退回，整体预留一到两周。

认证审核费以支付页显示为准，常见为 300 元/次、有效期一年，到期需再认证。费用归谁承担以合同为准：报价单口径是 SaaS 订阅已含这笔认证费，私有化由客户支付给腾讯。

### 3.1 企业

| 材料 | 要求 |
|---|---|
| 营业执照 | 彩色照片或扫描件，四角完整，统一社会信用代码和经营期限清晰，在有效期内 |
| 认证申请公函 | 在认证页面下载模板，填写后加盖公章。公章名称与执照主体名称一致，章印清晰 |
| 核验方式（页面给出哪些用哪些） | 法定代表人微信扫码，或企业对公账户小额打款后回填金额，或电子营业执照授权 |
| 对公账户（走打款核验时） | 开户名称与主体名称一致，并准备开户银行、账号。打款由腾讯发起，客户只回填到账金额 |
| 认证联系人 | 姓名、手机号、邮箱；页面要求时再提供身份证号及身份证正反面 |

### 3.2 个体工商户

| 材料 | 要求 |
|---|---|
| 个体工商户营业执照 | 彩色、完整、在有效期内，经营者姓名清晰 |
| 经营者身份证明 | 身份证正反面；核验多为经营者本人微信扫码或按页面完成人脸核验 |
| 申请公函 | 有公章则盖章。没有公章时按页面要求手写签名，必要时按手印 |

个体工商户通常没有对公账户，优先使用经营者本人核验，不要临时借用其他公司的执照或账户。

### 3.3 政府机关、事业单位、社会组织

| 材料 | 要求 |
|---|---|
| 主体证照 | 统一社会信用代码证书、事业单位法人证书或社会团体法人登记证书等，以页面列出的类型为准 |
| 认证申请公函 | 后台模板，加盖本单位公章 |
| 管理员身份证明 | 身份证正反面，以及页面要求的在职证明 |

### 3.4 上传前自查

- 证照是原件拍摄或扫描，不翻拍屏幕，不遮挡、不裁切。
- 主体名称、公章名称、对公账户户名三者一致，多一字或少一个地区名都会退回。
- 执照未过期，经营范围与所选行业大体相符。
- 联系人手机和邮箱在审核期间有人处理，补件通知错过会拖长周期。

## 4. 认证通过后交给实施的参数

这些不是证照，但没有它们无法联调。由企业微信超级管理员（或有应用管理权限的分级管理员）在后台创建，再经单独渠道交给实施负责人。不要发到业务大群，不要写进长期转发的邮件正文。

管理后台路径：应用管理 → 自建 → 创建应用。应用名称可用「智能客服」或客户指定名称，上传一张方形图标，可见范围至少包含要进客户群的内部成员。

| 参数 | 在哪里看 | 交给实施时的形式 |
|---|---|---|
| 企业 ID（CorpID） | 我的企业 → 企业信息 → 企业 ID | 以 `ww` 开头 |
| AgentId | 该自建应用页面 | 纯数字 |
| Secret | 同一应用页面，点击查看 | 只交付一次，部署写入服务器配置 |
| Token | 应用 → 接收消息 → 设置 API 接收 → 随机获取 | 与服务器配置保持同一份 |
| EncodingAESKey | 同上，随机获取 | 正好 43 位 |

部署完成前可以先生成 Token 和 EncodingAESKey 并记下，先不要点保存。回调地址要等域名已经能从公网访问后再保存：

- 私有化：`https://<客户域名>/wecom/callback`
- SaaS：`https://<租户域名>/wecom/callback`（域名由平台开通时分配）

同一页还需要：

| 后台项 | 填什么 |
|---|---|
| 企业可信 IP | 调用企微接口的服务器公网出口 IP。未配置时取 token 会失败 |
| 可信域名 | 回调使用的域名，不含 `https://` |
| 接收消息 URL | 上表中的 `/wecom/callback`。保存时企微会向该地址发一次校验，校验成功才算接通 |

域名、ICP 备案和 TLS 证书不在企微认证材料里，但没有它们回调保存不会成功。私有化由客户提前办；SaaS 的租户域名和证书由平台准备。备案常见要两到三周，和主体认证同时启动。

## 5. 客户群

| 事项 | 说明 |
|---|---|
| 群类型 | 企业微信客户群（外部群）。群主是已实名的本企业成员，客户用微信或企业微信进群 |
| 客户联系 | 在「客户联系」中确认使用范围包含群主，以及负责拉群的成员 |
| 把应用加进群 | 「客户联系 → 客户群」把该自建应用加入目标群，或由群主在群里添加该应用 |
| 联调群 | 先准备一个测试群，回调保存成功后再进正式客户群 |

可选：若要按成员账号识别 @，再提供机器人在通讯录中的账号（UserId）和群里显示的名称。不知道可以先留空。

## 6. 可选：会话内容存档

只在要把历史会话导入知识库时开通。实时 @ 问答不需要这项。

开通条件通常包括：企业已认证、按账号购买会话内容存档、相关员工完成授权。导出 JSON 或 CSV 后再交给导入功能。本系统不直接连接存档接口。费用按企微当时标价，常见为按账号按年计费，和上面的 300 元主体认证费是两笔钱。

## 7. 核对清单

打印或转发前逐项勾选。

**人**

- [ ] 已指定企微超级管理员，手机号可登录管理后台
- [ ] 认证联系人在审核期内能接电话、看邮件
- [ ] 已指定测试群群主（本企业成员）

**证照（按主体类型准备一种）**

- [ ] 企业：营业执照 + 盖章公函 + 法人扫码或对公打款
- [ ] 个体户：个体户营业执照 + 经营者身份证及本人核验
- [ ] 机关事业单位或社会组织：登记证书 + 盖章公函 + 管理员身份证

**认证结果**

- [ ] 主体认证已通过
- [ ] 企业 ID 已抄录

**应用与群**

- [ ] 自建应用已创建，AgentId、Secret 已通过单独渠道交付
- [ ] Token、43 位 EncodingAESKey 已生成并交付
- [ ] 企业可信 IP、可信域名已安排（有服务器出口 IP 和域名后再填）
- [ ] 测试客户群已建好，应用待回调成功后加入

**和认证并行、但不属于企微证照**

- [ ] 回调域名已备案并解析（私有化客户自备；SaaS 向平台要租户域名）
- [ ] 已确认是否要开通会话存档（不做历史导入则跳过）

## 8. 不需要准备的

- 个人微信账号、微信群主个人号、任何非官方微信协议。
- 微信支付商户号、公众号（本机器人不使用）。
- 公众号或小程序的 AppSecret，不能代替自建应用 Secret。
- 会话存档，除非确定要做历史会话导入。
