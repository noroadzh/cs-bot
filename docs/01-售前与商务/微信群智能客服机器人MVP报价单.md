## 四、商务条款

1. **付款节点（4:4:2）**：合同签订付 40%（¥11,000）；部署上线付 40%（¥11,000）；陪跑结束验收通过付 20%（¥5,500）。勾选增项包时按总价同比例执行。
2. **质保期**：验收通过起 3 个月，我方代码缺陷免费修复；需求变更、第三方接口变更、客户环境问题按变更计价。
3. **需求变更**：超出《功能清单》范围按 ¥1,200/人天另行计价，书面确认后执行。
4. **交付物**：成品系统 Docker Compose 部署包（绑定客户指定服务器使用）、部署与操作手册、知识库补录培训 1 次。**不含系统源码**。管理类操作（未命中问题导出、素材管理、历史导入审核、授权与配置查询）以**管理接口 + 操作手册内调用示例**（Basic Auth + 来源 IP 白名单）交付，运营可按手册直接操作；可视化界面归二期运营后台（见第五节）。
5. **不含项声明**：不含第三节所列第三方资源费用；不提供微信个人号方案；不承诺大模型准确率指标（以实测为准）；不含系统源码。
6. **授权模式（私有化形态）**：系统按成品授权交付——绑定合同指定的客户服务器使用，授权有效期与质保期对齐（到期可付费续期），管理群数量上限按合同约定（超量需升级授权）。授权期内换机、扩群可申请换发/升级授权证书，不收取开发费。
7. **授权与订阅（SaaS 形态）**：订阅期内按约定配额使用；到期后 7 天宽限期（问答可用、不可改知识库与加群），宽限期满系统进入受限模式（仅提示续期）；续费后即时恢复、数据不受影响。欠费超 60 天且经两次书面催告仍未支付的，我方有权在完成数据导出交付后删除实例与数据（出具删除确认单）。
8. **数据与责任划分（SaaS 形态）**：数据归客户所有，我方仅为受托处理方，双方签署数据处理与保密协议；我方承诺数据不跨租户使用、不用于模型训练、不对外提供；客户可随时导出本租户数据，注销时可申请全量导出与删除。
9. **SLA（SaaS 形态）**：工作时间可用性 ≥ 99.5%；计划内维护提前 3 个工作日通知并安排低峰时段；因企微、云厂商、LLM 第三方故障导致的中断不计入 SLA。
