## 1. 两种交付形态

| 维度 | 私有化版（形态 A） | SaaS 版（形态 B） |
|---|---|---|
| 部署位置 | 客户自有服务器 | 交付方云上，每租户独立实例 |
| 运维责任 | 客户（交付方质保期支持） | 平台运营 |
| 访问入口 | `https://<客户域名>` | `https://<租户域名>` |
| 知识库后台 | 客户内网 FastGPT（由交付方部署时提供入口） | `https://<租户域名>:8443` |
| 授权 | 交付方签发 license，绑定机器指纹 | 订阅期证书，绑定租户实例 |
| 配额 | 由 license 限制群数 | 平台按订阅档位配置：群数/文档/QA/素材 |
| 升级 | 客户按交付方通知执行 | 平台统一升级（提前 3 个工作日通知） |
| 数据位置 | 客户服务器 | 交付方云上（租户独立数据库/存储） |
| 备份 | 客户侧每日 02:00，保留 7 天 | 平台统一备份 |
| 到期处理 | license 到期→受限模式 | 订阅到期→7 天宽限期→暂停 |

## 2. 快速开始

### 2.1 SaaS 版

1. 联系平台运营开通，提供：企业名称、联系人、订阅档位、企微 CorpID。
2. 收到：租户域名、管理员初始口令（一次性展示）、FastGPT 根口令。
3. 在企微后台把应用回调 URL 配为 `https://<租户域名>/wecom/callback` 并保存校验。
4. 把机器人应用加入目标客户群。
5. 群里 @机器人 提问，收到带来源引用的回答即开通完成。

### 2.2 私有化版

1. 交付方完成部署后，提供：访问域名、管理员账号、FastGPT 后台入口。
2. 客户管理员在企微后台配置回调 URL `https://<域名>/wecom/callback`。
3. 把机器人应用加入目标群。
4. 群里 @机器人 提问验证；如需补充知识，进入 FastGPT 后台维护知识库。

## 3. 群内使用（所有成员）

### 3.1 如何提问

| 方式 | 说明 |
|---|---|
| @机器人 + 文字 | 推荐；问题尽量用一句完整的话描述 |
| 关键词触发 | 出厂默认前缀：`客服：`、`客服,`、`请问：`、`咨询：`（管理员可在 `config/keywords.yml` 调整） |
| @机器人 + 图片 | 识别图片中的文字并归纳为问题；图片需 ≤10MB、含可识别文字 |

回答会以“主动消息”发送到群里，并 @ 提问人；命中知识库时附带来源引用（最多 2 条）。

### 3.2 不支持的消息

- @机器人的**语音、视频、文件**不会解析，会回复引导话术：请改用文字描述（可注明文件名）。
- 未 @机器人 的普通聊天不触发，机器人保持静默。

### 3.3 回答行为说明

| 现象 | 含义 | 建议 |
|---|---|---|
| 回答末尾有 `—— 来源：《文档名》` | 命中知识库 | — |
| “抱歉，这个问题超出了我的知识范围…” | 未命中，已记录到未命中清单 | 联系管理员补充知识 |
| “系统繁忙，请稍后再试或联系人工客服” | 模型/知识库暂时不可用 | 稍后重试 |
| “提问太频繁，请稍后再试” | 限流（每群 20 条/分钟、每人 5 条/分钟） | 稍后再问 |
| “抱歉，该内容不便回复，请联系人工客服。” | 出站内容命中敏感词 | 联系人工客服 |
| 仅回复授权/续期提示 | 授权失效或订阅到期 | 联系管理员续期 |

### 3.4 素材类回答

部分答案会附带图片/文件/视频素材（如操作截图、文档）。单条答案最多 2 个素材；素材发送失败时会补发降级提示。

## 4. 知识运营（管理员 / 运营）

### 4.1 知识库后台

- **SaaS 版**：`https://<租户域名>:8443`，用平台提供的 FastGPT 根口令登录。
- **私有化版**：入口由交付方按客户网络策略提供（默认不暴露公网）。

在 FastGPT 后台维护知识库：新建/选择知识库 → 上传文档（PDF/Word/文本等）→ 设置切片 → 发布。发布后新提问即可检索到；正在进行的会话不受影响。

### 4.2 历史聊天导入（可选）

适用于把历史客服记录转成知识库语料：

1. 管理员上传会话文件（CSV/JSONL/TXT/XLSX，需含 question/answer 列）。
2. 系统后台解析、清洗、配对、脱敏，生成审核清单（xlsx）。
3. 管理员逐条审核（保留/修改/丢弃），确认后写入独立数据集 `历史语料-<任务号>`。
4. 如需撤回，执行回滚删除该批次。

> 私有化版由客户管理员通过管理接口操作；SaaS 版可联系平台运营协助。导入任务单任务串行，内存占用过高会自动暫挂并在空闲时续跑。

### 4.3 素材管理

管理员上传素材（图片/文件/视频，单文件 ≤20MB、视频 ≤10MB），在 FastGPT 答案中用 `[[素材:<素材ID>]]` 引用；单条答案最多 2 个。删除素材后，引用该素材的答案将不再附带素材。

### 4.4 未命中问题处理

定期导出未命中清单（xlsx/json），补充到知识库或安排人工回复：

- 私有化版：`GET https://<域名>/admin/miss-records?from=YYYY-MM-DD&to=YYYY-MM-DD&format=xlsx`
- SaaS 版：联系平台运营导出，或在租户管理入口申请。

## 5. 授权、订阅与配额

### 5.1 SaaS 版

- 订阅到期前 30/15/7 天提醒；到期后进入 **7 天宽限期**（问答可用，但新增群受限）；宽限期满暂停，仅提示续期。
- 续费后即时恢复，无需重建实例。
- 配额按档位配置：群数、文档数、QA 对数、素材容量；超限时新增群/导入/上传会被拒绝并提示。
- 配额不足可联系平台运营调整。

### 5.2 私有化版

- license 文件绑定机器指纹与有效期；到期后机器人进入受限模式（仅回授权提示）。
- 续期：管理员导出授权申请码 → 交付方签发新 `license.lic` → 替换后重启或调用热加载。
- 群数上限由 license 的 `maxChats` 控制；超出后新群接入被拒绝并告警。
- 更换服务器会导致指纹变化，需重新申请 license。

## 6. 数据、备份与注销

| 项 | 私有化版 | SaaS 版 |
|---|---|---|
| 数据位置 | 客户服务器 | 平台云（租户独立库） |
| 备份 | 每日 02:00，保留 7 天 | 平台统一备份 |
| 导出 | 由交付方协助（pg/mongo/assets） | 可随时申请，导出包含知识库与业务数据 |
| 注销 | 客户自行删除或委托交付方 | 导出确认 → T+7 删除（含备份）→ 删除确认单 |

## 7. 常见问题（FAQ）

1. **@机器人没反应**：确认应用已在群内；确认未处于授权受限/暂停状态；确认触发词匹配。
2. **总回答“超出知识范围”**：知识库缺少相关内容，补充文档或导出未命中清单。
3. **图片没识别**：图片可能无文字、超过 10MB 或识别服务暂不可用，改用文字提问。
4. **提示“提问太频繁”**：触发限流，稍后再问。
5. **语音/视频/文件无回答**：不支持解析，请转文字。
6. **答案里的素材没发出来**：素材可能已删除/停用，或单条超过 2 个。
7. **SaaS 到期后还能用吗**：7 天宽限期内问答可用，续费后立即恢复。
8. **私有化换服务器后不能用**：license 绑定机器指纹，需重新签发。
9. **如何看当天用了多少**：私有化版查授权状态与管理接口；SaaS 版联系平台运营。
10. **数据会出客户环境吗**：私有化版全部在客户服务器；SaaS 版存储在平台云，仅平台运营可运维。

## 8. 支持与联系

- **私有化版**：交付方质保期内远程支持；提供 `docker compose -f deploy/docker-compose.yml ps` 与最近日志。
- **SaaS 版**：联系平台运营（工单/值班群），提供租户域名与问题时间点。
